📖 Panduan

Alur Usaha Anda

Pagi (05.00) — Buka lapak, jual barang dari belanja kemarin.
Siang (11.00) — Pulang, hitung omzet. Input di Tutup Hari.
Sore (16.00) — Belanja untuk besok. Input di Belanja.
Malam — Cek Beranda, lihat laba dan saldo.

Rumus Laba

Laba = Omzet − Belanja Hari Ini − Biaya Sore

Saldo

Saldo hari ini = Saldo kemarin + Laba hari ini

Lain-lain Dinamis

Di Tutup Hari, bagian "Lain-lain Sore" bisa diisi banyak pengeluaran dengan keterangan masing-masing. Setiap item tersimpan otomatis.

Kapan Tarik/Setor Saldo?

  • Tarik — Ambil uang dari saldo untuk keperluan pribadi atau tambahan modal
  • Setor — Tambah uang ke saldo dari sumber luar

💬 Bantuan

Pertanyaan Umum

Q: Kenapa laba hari ini berbeda dengan perkiraan?

A: Laba = Omzet − Belanja − Biaya. Cek salah satu dari 3 komponen.

Q: Kenapa saldo bisa minus?

A: Kalau Anda tarik lebih besar dari saldo. Artinya Anda "utang" ke tabungan sendiri.

Q: Bagaimana cara input banyak pengeluaran lain-lain?

A: Di Tutup Hari, isi Keterangan + Jumlah → tap "+ Tambah". Ulangi untuk pengeluaran lain.

Q: Data saya hilang, apa yang harus dilakukan?

A: Buka Pengaturan → Download Backup. Data di server tetap aman.
